E-Means Clustering Architecture

Algorithmic foundations and empirical scaling laws of the e-means clustering method (Meta FAIR, arXiv:2611.09501).

Algorithmic Formulation

Traditional Lloyd's k-means clustering requires complete epoch passes before updating centroid locations. Streaming approaches (such as MacQueen's) accumulate statistics indefinitely, freezing early centroid errors.

e-means solves this by using mini-batch updates combined with an Exponential Moving Average (EMA) applied to both vector sums and point counts:

# E-Means Mini-Batch EMA Update Equations
S_j <- (1 - alpha_t) * S_j + alpha_t * s_j
N_j <- (1 - alpha_t) * N_j + alpha_t * n_j
c_j = S_j / N_j

Where:

  • S_j: Accumulated weighted vector sum for cluster j.
  • N_j: Accumulated weighted point count (mass) for cluster j.
  • s_j, n_j: Vector sum and count of points assigned to cluster j within the current mini-batch.
  • alpha_t: Annealed step rate governed by a cosine decay schedule.

Empirical Scaling Laws

A major contribution of e-means is replacing hyperparameter grid searches with explicit scaling laws computed directly from dataset size (n), cluster count (k), and target epoch budget (T):

1. Batch Size Scaling Law

B = 0.035 * (k ^ 0.13) * (n ^ 0.88) * (T ^ 0.81)

2. Initial Step Size Scaling Law

alpha_0 = min(0.824 * (k ^ -0.46) * (B ^ 0.90) * (n ^ -0.45) * (T ^ -0.11), 1.0)

3. Cosine Annealing Schedule

Across training progression p in [0, 1] (where p = step / total_steps):

alpha(p) = alpha_0 * (0.1 + 0.9 * 0.5 * (1 + cos(pi * p)))

Dead-Cluster Revival

In streaming and mini-batch clustering, clusters can experience assignment starvation ("dead clusters"). e-means prevents cluster collapse through periodic revival checks:

  • Every 5 update steps, cluster masses N_j are compared against 0.1 * mean(N).
  • Starved clusters are revived by selecting donor clusters sampled proportionally to mass.
  • The donor centroid is perturbed slightly and its mass shared, preventing empty partitions.
