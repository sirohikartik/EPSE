FASTA Ingestion & CPU Embedder Pipeline

Detailed documentation for sequence streaming across diverse bioinformatics repositories and memory-efficient CPU representation generation.

Universal FASTA Streaming (epse.fasta)

Bioinformatics databases employ varying header conventions and compression formats. The epse.fasta.parse_fasta() generator streams records incrementally without buffering the entire input file into memory.

Sequence Sanitization

During iteration, sequences undergo standard bio-cleaning:

  • Removal of internal and trailing whitespace characters (spaces, line breaks, carriage returns).
  • Upper-casing of IUPAC amino acid characters.
  • Stripping of termination symbols (such as trailing * characters).

CPU Embedding Generation (epse.embedder)

Dense sequence representations are produced using the ESM-2 transformer model (facebook/esm2_t12_35M_UR50D) running strictly on CPU hardware.

Residue Attention Pooling

Unlike raw classification representations, protein embeddings in EPSE use attention-masked mean pooling over valid sequence tokens:

# PyTorch CPU mean pooling with attention mask
mask = attention_mask.unsqueeze(-1).expand_as(last_hidden_state).float()
sum_embeddings = torch.sum(last_hidden_state * mask, dim=1)
sum_mask = torch.clamp(mask.sum(dim=1), min=1e-9)
mean_pooled = sum_embeddings / sum_mask

Batching on CPU

CPU inference is batched (default batch size: 8) to optimize memory bandwidth and cache locality while maintaining low latency. Thread counts are configurable via torch.set_num_threads.

L2 Normalization & Spherical Geometry

Every generated embedding is normalized onto the unit hypersphere: v = v / ||v||_2. Under unit normalization:

  • Cosine similarity equals the inner dot product: cos(u, v) = u . v.
  • Squared Euclidean distance maps monotonically to cosine distance: ||u - v||^2 = 2 - 2(u . v).
  • Cluster centroids can be projected to unit length, enabling fast spherical e-means clustering and SIMD dot products.
