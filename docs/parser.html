Embedding generation phase

This page describes the embedding generation phase: how inputs are parsed, normalized, and converted into vectors.

Pipeline

  1. Ingest source content
  2. Parse and normalize text units
  3. Generate embeddings via the project embedding functions
  4. Persist or serve vectors for retrieval

Functions involved

  • get_embeddings_batch — defined in parser\parse.py

Insights

Each stage should stay side-effect light and testable. When the backend model changes, re-embed consistently rather than mixing vector spaces.
